## 🚀 Deployment

This landing page is hosted using **GitHub Pages**. Any changes pushed to the `main` branch are automatically reflected in the live site.

### Steps to Deploy Changes:
1. Make edits to the `index.html` file.
2. Commit changes with a meaningful message.
3. Push to the `main` branch.

The updates will be live within a few minutes at the provided GitHub Pages URL.
